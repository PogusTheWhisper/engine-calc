## 3. STEP 1 — ข้อมูลเครื่องยนต์

รับค่า **Bore (mm)** และ **Stroke (mm)** แล้วคำนวณ 4 อย่าง:

### 3.1 ความจุกระบอกสูบ (CC)

```
CC = π/4 × Bore² × Stroke / 1000
```

**ที่มา:** ปริมาตรทรงกระบอก = พื้นที่หน้าตัด × ความยาว
หาร 1000 เพื่อแปลง mm³ เป็น cc

**ตัวอย่าง:** bore 57, stroke 58.7 → **149.79 cc**

---

### 3.2 ขนาดวาล์วและลิ้นเร่ง

```
วาล์วไอดี   = Bore × 0.50
วาล์วไอเสีย = Bore × 0.42
ลิ้นเร่ง     = Bore × 0.60
```

**เหตุผล (สูตรช่างแต่ง):**
- ไอดีใหญ่กว่าไอเสีย ~19% เพราะอากาศเย็นมีความหนาแน่นต่ำ ต้องการพื้นที่ไหลเข้ามาก
- ลิ้นเร่งใหญ่ที่สุดเพื่อไม่เป็นคอขวด

✅ **ข้อดี:** ใช้กะระยะแคมและฝาสูบได้เร็ว ผ่านสนามแข่งมาแล้ว
❌ **ข้อเสีย:** ค่ากลาง ไม่เหมาะ turbo, ไม่นับ port flow จริง

---

### 3.3 B/S Ratio — ประเภทเครื่อง

```
B/S = Bore / Stroke
```

| ค่า | ประเภท | ลักษณะ | ตัวอย่างเครื่อง |
|-----|--------|--------|----------------|
| **< 0.9** | Long Stroke | ช่วงชักยาวกว่าลูกสูบ | Wave 110, Click 125 |
| **0.9 – 1.1** | Square | ลูกสูบ ≈ ช่วงชัก | Wave 125, MSX125 |
| **> 1.1** | Over Square | ลูกสูบใหญ่กว่าช่วงชัก | CBR250RR, R15 |

**ข้อดี/ข้อเสียของแต่ละแบบ:**

| ประเภท | ✅ ข้อดี | ❌ ข้อเสีย |
|--------|----------|------------|
| Long Stroke | torque ดี รอบต่ำ ออกตัวแรง ประหยัด | RPM สูงไม่ได้, HP จำกัด |
| Square | สมดุล ใช้งานทั่วไปดี | ไม่เด่นด้านใดด้านหนึ่ง |
| Over Square | RPM ขึ้นไว HP เยอะ เสียงเร้าใจ | torque รอบต่ำต่ำ ต้องลากรอบ |

## 4. STEP 2 — น้ำมันเชื้อเพลิง

รถซิ่งใช้ **3 ชนิด** คือ Gasohol 95, E20, E85

### 4.1 ตารางคุณสมบัติ

| น้ำมัน | CR | AFR Stoich | Injector × CC | จุดระเบิด BTDC | เอทานอล |
|--------|----|-----------|---------------|----------------|---------|
| **95** | 10.5 : 1 | 14.7 : 1 | × 1.0 | 34° | 10% |
| **E20** | 11.5 : 1 | 13.8 : 1 | × 1.2 | 35° | 20% |
| **E85** | 13.0 : 1 | 9.8 : 1 | × 1.3 | 38° | 85% |

### 4.2 ทำไม CR ต่างกัน?

**Compression Ratio (กำลังอัด)** = ปริมาตรลูกสูบล่างสุด / บนสุด

- **ออกเทนสูง** → ต้านการน็อค (knock) → ใช้ CR สูงได้
- **เอทานอล** เพิ่มออกเทน + ช่วยเย็นห้องเผาไหม้ → ยิ่งมาก ยิ่งใช้ CR สูงได้

✅ **CR สูง:** เผาสมบูรณ์ พลังเพิ่ม
❌ **CR สูงเกิน:** น็อค → ลูกสูบทะลุ พังทันที

---

### 4.3 ห้องเผาไหม้ (Combustion Chamber)

```
Chamber = CC / (CR − 1)
```

**ที่มา:** จากนิยาม CR เอง — ใช้บอกช่างกลึงฝาสูบว่าต้องคว้านให้ปริมาตรเหลือกี่ cc

**ตัวอย่าง:** 149.79 / (10.5−1) = **15.77 cc**

---

### 4.4 ขนาดหัวฉีด

```
Injector (cc/min) = CC × inj_mult
```

| น้ำมัน | × | เหตุผล |
|--------|---|--------|
| 95  | 1.0 | base — น้ำมันเบนซินปกติ |
| E20 | 1.2 | +20% เพราะเอทานอลมีพลังงานต่อปริมาตรน้อยกว่า |
| E85 | 1.3 | +30% เพราะเอทานอลเยอะมาก |

✅ **ข้อดี:** ป้องกัน lean (ผสมบาง) → เครื่องร้อน → พัง
❌ **ข้อเสีย:** ค่าประมาณ ของจริงต้องดู dyno + wideband O2

---

### 4.5 AFR (Air-Fuel Ratio)

อัตราอากาศต่อน้ำมัน (โดยน้ำหนัก) ที่เผาไหม้สมบูรณ์

- ค่าน้อย = น้ำมันเยอะ (rich) → กำลังเยอะ มลพิษสูง
- ค่ามาก = น้ำมันน้อย (lean) → ประหยัด แต่ร้อน เสี่ยงพัง

**รถซิ่งจูน AFR ~12.5–13.5** (rich กว่า stoich) เพราะให้ HP สูงสุด

---

### 4.6 จุดระเบิด (BTDC)

```
BTDC = องศาก่อนลูกสูบถึง TDC ที่จุดระเบิด
```

| น้ำมัน | BTDC | เหตุผล |
|--------|------|--------|
| 95  | 34° | base |
| E20 | 35° | เอทานอลเผาช้ากว่าเล็กน้อย ต้องจุดเร็วขึ้น |
| E85 | 38° | เผาช้าที่สุด ต้องล่วงหน้ามากที่สุด |

✅ **จุดล่วงหน้าพอดี** → กดดันลูกสูบสูงสุดที่ 10–20° ATDC → torque สูงสุด
❌ **ล่วงหน้าเกิน** → น็อค → พัง

## 5. STEP 3 — ประมาณกำลัง

### 5.1 BMEP (ความดันเฉลี่ยในกระบอกสูบ)

```
BMEP = 900 + (CR − 10) × 30  [kPa]
```

**ค่าอ้างอิงโลกจริง:**
- เครื่อง stock NA: 700–900 kPa
- เครื่อง tuned NA: 900–1100 kPa
- เครื่อง race NA: 1100–1300 kPa
- เครื่อง turbo: 1500–2500 kPa

---

### 5.2 สูตรกำลัง (4-stroke)

```
P(kW)     = BMEP × CC × RPM / 120,000,000
HP        = kW / 0.7457
Torque    = 9549 × kW / RPM
```

**ที่มา:** `P(W) = BMEP × Vd × (RPM/60) / 2`
- หาร 60 แปลง RPM → rev/s
- หาร 2 เพราะ 4-stroke = 1 power stroke ต่อ 2 รอบ

**ตัวอย่าง:** 149.79 cc, BMEP 915, RPM 9500
```
kW = 915 × 149.79 × 9500 / 120,000,000 ≈ 10.85
HP = 14.55, Torque ≈ 10.9 Nm
```
ตรงกับเครื่อง Wave125/MSX125 แต่งหัวโต+แคม

---

### 5.3 RPM พลัง, Cam Duration, Valve Lift

ขึ้นกับ B/S Ratio:

| ประเภท | Peak RPM | Cam Duration | Valve Lift |
|--------|----------|--------------|------------|
| Over Square (B/S>1.05) | 11,000 | 270–285° | bore × 0.28 |
| Square (0.9–1.05) | 9,500 | 260–270° | bore × 0.26 |
| Long Stroke (<0.9) | 8,000 | 250–260° | bore × 0.24 |

**เหตุผล:** Mean Piston Speed limit ~20–25 m/s
- Stroke สั้น → piston speed ต่ำ → RPM ขึ้นได้สูง
- Stroke ยาว → piston speed สูงเร็ว → จำกัด RPM

## 9. ข้อจำกัดและคำเตือน

⚠️ ค่าทั้งหมดเป็น **การประมาณ** สำหรับ:
- เครื่องยนต์ **4-stroke สูบเดี่ยว NA** เท่านั้น
- ไม่ใช่ค่าจาก **dyno จริง**
- ไม่นับ: ฝาสูบจริง, แคม, ท่อ, ECU map, น้ำหนัก, อุณหภูมิอากาศ
- BMEP เป็น heuristic — ของจริงคลาด ±20%

**ใช้เป็นแนวทาง** ตอนวางแผนงานแต่งเท่านั้น ก่อนแต่งจริงควรปรึกษาช่างผู้เชี่ยวชาญ และยืนยันด้วย dyno
